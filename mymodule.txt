Complete Python Modules Notes

1. Definition of Module
A module is a file containing Python definitions, functions, variables, and classes. It helps
organize code and reuse it in different programs. The file extension must be .py.

2. Features of Module
• Contains functions, variables, and classes
• Improves code reuse
• Helps organize large programs
• Reduces code duplication
• Easy to maintain and debug

3. Creating a Module

Step 1: Create a file named mymodule.py
Step 2: Write code inside the file

Example: mymodule.py

 print("Hello, " + name)

 "name": "John",

}

4. Using a Module
Import module using import keyword
Example:
import mymodule
mymodule.greeting("Sona")

5. Import with Alias
You can rename module using 'as' keyword

import mymodule as mx
mx.greeting("Sona")
Example:
import mymodule
mymodule.greeting("Sona")

6. Variables in Module
A module can contain variables like list, dictionary, etc.
import mymodule
print(mymodule.person1["age"])
Example:
import mymodule
mymodule.greeting("Sona")

7. Import Specific Item
You can import specific function or variable using from keyword
from mymodule import greeting
greeting("Sona")
Example:
import mymodule
mymodule.greeting("Sona")

8. Built-in Modules
Python provides built-in modules like math, sys, platform, datetime, random.
